Standalone text/optional offline microphone Agent; all robot execution is
fake.

options:
  -h, --help            show this help message and exit
  --fake                Offline FunctionModel, no API key needed
  --config CONFIG
  --vosk-model VOSK_MODEL
                        Local unpacked Chinese Vosk model directory
  --asr-backend {vosk,sensevoice}
                        Question ASR; wake remains local Vosk
  --asr-model-dir ASR_MODEL_DIR
  --no-voice-interrupt  Strict half duplex; disable addressed voice interrupt
                        channel
  --idle-timeout IDLE_TIMEOUT
                        Seconds of idle before local sleep announcement
  --audio-device AUDIO_DEVICE
                        Input index or device-name substring; default built-in
                        Realtek
  --audio-samplerate {16000,22050,44100,48000}
                        Native PCM sample rate, also passed to Vosk; no hidden
                        resampling
  --tts                 Offline Windows Chinese SAPI5 output
